# Самопроверка своей реализации

Проверена собственная реализация `FilterAndSort` в библиотеке `NotificationLibrary`. Это не инспектирование pull request другого студента.

## Проверка требований

- Реализована фильтрация по статусу прочтения, типам уведомлений, тексту в заголовке и содержимом, а также минимальному приоритету.
- Реализована сортировка по дате, приоритету и заголовку с выбором направления.
- Для `null` коллекции выбрасывается `ArgumentNullException`.
- Если параметры фильтрации не заданы, применяется сортировка по дате.

## Возможные улучшения

- При дальнейшем расширении проекта можно выделить фильтрацию в отдельный сервис или интерфейс.
- Если появится больше вариантов сортировки, можно вынести их в отдельные стратегии.

Это возможные направления развития, а не выявленные дефекты: для текущего объёма задания отдельные интерфейсы и стратегии не обязательны.

## Результат

Самопроверка не заменяет требуемое заданием инспектирование pull request другого студента. Внешний PR не проверялся, поэтому замечания к чужой работе и вывод по такому инспектированию пока отсутствуют.
