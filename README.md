# Практическая работа №4

Репозиторий для выполнения практической работы по инспектированию программного кода.

- библиотека классов `NotificationLibrary`
- реализация фильтрации и сортировки уведомлений
- отчет по работе и результат инспектирования

## Как запустить
```bash
dotnet build NotificationLibrary/NotificationLibrary.csproj
```
